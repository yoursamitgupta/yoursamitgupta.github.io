The Open-Source Developer Suite

A coordinated ecosystem of developer tools designed to make interacting with AI models, agents, and pipelines dramatically faster, cheaper, and more reliable.

🔥 ↗

PromptForge

The open-source prompt engineering browser extension. Directly attaches to Claude, ChatGPT, Copilot, & Gemini to eliminate conversational drift.

Manifest V3 -83% Tokens
⚡ ↗

ContextSlim

Semantic AST context minifier for Cursor, Claude Code, and Aider. Condenses codebases by 80%+ while preserving types and docstrings.

npx context-slim Zero Deps
🛡️ ↗

ToolGuard

Static analysis linter for Model Context Protocol (MCP) and function calling schemas. Stops hallucinations and vague parameter definitions.

npx toolguard MCP Linter
📋 ↗

PromptSpec

Declarative prompt contract and regression testing for CI/CD. Assert JSON schemas, token limits, latency, and regex rules.

npx promptspec CI / Evals
🗺️ ↗

git-narrate

Git extension converting staged diffs into architectural summaries and visual Mermaid sequence diagrams for GitHub Pull Requests.

git narrate Mermaid PRs
📊 ↗

TokenMeter

Local multi-provider LLM token and spend monitoring HUD. Tracks spend, velocity, and daily budget limits across OpenAI, Claude, and Gemini.

npx tokenmeter Budget HUD
